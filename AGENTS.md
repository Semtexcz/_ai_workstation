# Global Agent Contract

These instructions are workstation-level defaults. Project-local `AGENTS.md` files override or specialize them where the agent harness supports layered instructions.

- Prefer explicit task scope and confirm important ambiguity before acting.
- Minimize loaded context; read only the files needed for the current decision.
- Do not silently expand scope beyond the user's request.
- Preserve evidence for meaningful claims, decisions, and validation results.
- Prefer deterministic tools, parsers, and tests over LLM reasoning when practical.
- Respect project-local instructions, security boundaries, and approval policies.
- Keep project goals, milestones, tasks, acceptance criteria, and lifecycle rules out of workstation-level guidance.
