# Generic Research

## Trigger

Use this skill when the answer depends on source material that is not already present in the current context, or when claims need current or cited support.

## Method

1. Define the research question and the minimum evidence needed.
2. Prefer primary sources, official documentation, standards, source repositories, published papers, or original datasets.
3. Use deterministic search, file inspection, or database queries before asking a model to infer.
4. Record enough source metadata for another person to verify the claim.
5. Distinguish facts, interpretation, and unresolved uncertainty.

## Boundaries

Do not turn research into project planning, task tracking, or implementation unless explicitly asked.

## Escalate

Escalate ambiguity when sources disagree, when the topic is high stakes, when recency matters and cannot be verified, or when the available evidence is indirect.
