# Generic Task Review

## Trigger

Use this skill near the end of a task or before reporting completion.

## Method

1. Compare the result against the user's explicit request.
2. Check that generated files and installed state match documented ownership.
3. Run deterministic validation where available.
4. Report exact commands and outcomes for important checks.
5. Call out residual risk or skipped checks.

## Boundaries

This is not a project Definition of Done. It verifies the current task only.

## Escalate

Escalate when tests cannot run, validation is incomplete, state differs from documentation, or completion would depend on hidden workstation state.
