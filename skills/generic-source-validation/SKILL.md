# Generic Source Validation

## Trigger

Use this skill before relying on uncertain sources, copied snippets, generated citations, dependency claims, or documents whose origin is unclear.

## Method

1. Prefer authoritative originals over summaries, mirrors, indexes, or reposts.
2. Check publication date, author or organization, version, and whether the source applies to the user's environment.
3. Cross-check critical claims against at least one independent source when practical.
4. Treat snippets and search results as discovery only until the underlying page or file is inspected.
5. Note limitations plainly.

## Boundaries

This skill validates evidence quality; it does not decide project priority or define acceptance criteria.

## Escalate

Escalate when evidence is stale, contradicted, unverifiable, security-sensitive, legal, medical, financial, or likely to affect irreversible actions.
