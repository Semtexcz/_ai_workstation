# Generic Planning

## Trigger

Use this skill for ambiguous, multi-step, high-risk, or cross-system work where order and scope affect outcome.

## Method

1. State the objective and known constraints.
2. Identify the smallest useful sequence of reversible steps.
3. Separate discovery, design, implementation, verification, and cleanup.
4. Keep plans current as evidence changes.
5. Prefer concrete checks over subjective confidence.

## Boundaries

Do not create project milestones, backlogs, ownership plans, or lifecycle rules. Those belong to project repositories.

## Escalate

Escalate when scope is unclear, assumptions are risky, required authority is missing, or a step could overwrite user-managed state.
